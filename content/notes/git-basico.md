# Git: o essencial para começar

O Git acompanha versões do projeto. Um fluxo seguro começa observando o estado atual, revisando as mudanças e criando commits pequenos e claros.

```bash
git status
git diff
git add caminho/do/arquivo
git commit -m "feat: descreve a mudança"
```
